<original_problem_statement>
**PRODUCT OVERVIEW: CashJama**
CashJama is a mobile-first fintech operations platform for doorstep cash-to-bank deposit requests. It manages service requests, field agent (BC) assignment, OTP/GPS verification, and operational tracking. It does NOT store or transfer money, act as a wallet, or support digital payments.

**ROLES:**
-   **User:** Requests cash deposits.
-   **BC Agent:** Fulfills deposit requests.
-   **Admin:** Manages the platform via a web dashboard.

**KEY FEATURES - USER APP:**
-   **Authentication:** Mobile number + OTP login.
-   **Deposit Request:** Enter amount, view fee, select location, confirm.
-   **Tracking:** View assigned BC Agent, live location, and job status.
-   **Verification:** Job-specific OTP is shown to the user to share with the BC Agent.
-   **History:** View past requests.

**KEY FEATURES - BC AGENT APP:**
-   View and accept available jobs.
-   Live GPS tracking during jobs.
-   Enter user's OTP to verify and proceed.
-   View earnings (service fees collected).

**TECH STACK:**
-   **Backend:** FastAPI, MongoDB
-   **Frontend:** Expo React Native (Android-first)
-   **Integrations:** MSG91 (OTP), Google Maps SDK (mocked for now)

**USER REQUESTS DURING THIS SESSION:**
-   Implement a minimal, pilot-focused BC Agent flow.
-   Fix numerous P0 and P1 bugs in the User flow related to navigation, state management, UI consistency, and time display.
-   Create operational documentation for the pilot.
-   Fix critical pilot-blocking bugs for both User and BC Agent flows, including state persistence, OTP handling, and status refresh issues.
